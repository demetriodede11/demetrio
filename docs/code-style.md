## Функции и типы

Функции и компоненты объявляйте через `const` и стрелочную функцию.
Если функция только возвращает выражение, используйте запись без блока:

```ts
type TProps = { title: string };

const getTitle = ({ title }: TProps) => title.trim();
```

Имена компонентов — `PascalCase` (`Header`), функций — `camelCase` (`getFaqList`).
Имена псевдонимов типов начинаются с `T`: `TProps`, `TFaqListResponse`.
Для импорта типов используйте `import type`.

## Импорты

Группы разделяйте пустой строкой: пакеты и модули Node.js, затем алиасы проекта,
затем относительные импорты. Доступные алиасы:

- `$shared/*` — `src/shared/*`;
- `$modules/*` — `src/modules/*`;
- `$widgets/*` — `src/widgets/*`;
- `$public/*` — `public/*`.

В импортах `.ts` и `.tsx` расширение опускайте; для `.mjs` указывайте явно.

## Форматирование

Отступ — 2 пробела, одинарные кавычки, пробелы внутри фигурных скобок.
Параметры стрелочных функций пишутся в круглых скобках. Prettier переносит
строки с ориентиром в 100 символов; окончательный формат задают конфиги проекта.

```bash
npm run lint:fix
npm run prettier:format
```

В WebStorm используйте Prettier проекта при форматировании; общие настройки
отступов и перевода строк берутся из `.editorconfig`.
