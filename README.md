# Demetrio

Приложение на Next.js и TypeScript.

## Запуск

```bash
npm ci
npm run dev
```

Приложение доступно по адресу [localhost:3000](http://localhost:3000).
Для работы запросов настройте [подключение к серверу API](docs/api.md).

## Проверки

```bash
npm run lint
npm run check:types
npm run prettier:check
```
